## I. GIỚI THIỆU & TINH THẦN CỦA WEBSITE
Website được thiết kế như một món quà tinh thần đặc biệt lưu giữ những kỷ niệm bình dị mà sâu sắc:
- Trân trọng ngày đầu tiên gặp gỡ tình cờ.
- Trân trọng chuyến đi dạo biển Vũng Tàu, lượn xe hóng gió và ngồi uống ly nước cùng nhau.
- Lưu giữ bức ảnh kỷ niệm duy nhất: Hai ngón tay — Một lời chào, cũng là một lời tạm biệt.
- Mang tinh thần: **Đẹp nhưng không phô trương – Lãng mạn nhưng không sến – Chân thành và trân trọng.**

## II. HƯỚNG DẪN TRIỂN KHAI LÊN GITHUB PAGES / VERCEL

### 1. Đẩy lên GitHub & Kích hoạt GitHub Pages
1. Thêm commit và đẩy mã nguồn lên GitHub:
   ```bash
   git add .
   git commit -m "Cảm ơn em, vì tất cả"
   git push origin main
   ```
2. Trên GitHub, vào kho lưu trữ của bạn:
   - Vào mục **Settings** > **Pages**.
   - Tại phần **Branch**, chọn nhánh `main` và thư mục `/(root)`, sau đó nhấn **Save**.
   - Chờ khoảng 1-2 phút, GitHub sẽ cung cấp đường link website trực tuyến (dạng `https://<username>.github.io/<tên-repo>/`).

### 2. Triển khai lên Vercel (Tùy chọn)
1. Đăng nhập [https://vercel.com](https://vercel.com).
2. Chọn **Add New Project**, liên kết với repo GitHub này và bấm **Deploy**.
3. Bạn sẽ nhận được đường link miễn phí với tốc độ tải trang cực nhanh.
